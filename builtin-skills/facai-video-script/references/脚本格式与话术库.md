## 二、五段式脚本结构

### 第一段：开场钩子（前3秒）

目标：抓住注意力，引发停留

**价格钩子**（最常用）：
- "才X毛多一套，便宜到不敢相信！"
- "一百块钱到手这么多翻糖糕你敢信？"
- "四毛多一套，真的太划算了！"
- "一块多一套，这个价格买到就是赚到！"

**情绪钩子**：
- "完了完了，姐妹们翻糖买早了！"
- "烘焙姐妹们谁懂啊！"
- "姐妹们开春季法彩盒装刀叉又上新包装了！"
- "太方便了，再也不用说啊，忘了给他拿刀了！"

**问题钩子**：
- "还没买蛋糕刀叉的朋友们，刷到这条视频，你可真是赚到了！"
- "你们现在用的刀叉盘啊，都选错了！"
- "做烘焙的姐妹们看过来了！"

### 第二段：痛点激发 / 对比反差

目标：引发共鸣，铺垫产品

**刀叉痛点**：
- "廉价刀叉难看、软塌、不卫生，蛋糕再贵也不上档次"
- "刀软得切不动，叉子一掰就断，盘子承重差，蛋糕放上去直接塌底"
- "一咬就碎，顾客吃着体验感差"
- "用那种小黑叉子老是粘毛毛"

**翻糖痛点**：
- "以前翻糖硬邦邦，砸核桃、砸钉子都不在话下"
- "冬天太冷不想揉翻糖"
- "自己准备大几十才能做一个"

**果酱痛点**：
- "还在自己熬果酱？费时费力还容易氧化出水"
- "一打开哈吸汤寡水的一股子香精味"
- "很多店主总担心夹心一成不变"

### 第三段：产品卖点展示

**刀叉量化话术**：
- "单个足足X克，刀叉反复弯折不易断裂"
- "超厚白卡材质，承托力强，蛋糕放上去稳稳拖住"
- "奶白色设计，精美纸袋包装，档次特别高"
- "五盘五叉，全配齐：刀叉盘、生日帽、蜡烛、火柴"
- "没有对比就没有伤害"

**翻糖量化话术**：
- "一包足足六百克"
- "里面分成了三小包，好揉好捏，很轻松就能揉到拉丝的状态"
- "擀平的翻糖直接脱模就可以了，塑形好不开裂"
- "质地柔软，轻松揉到拉丝状态"
- "塑性好，不变形不开裂"

**果酱/夹心量化话术**：
- "足足X大包，近三个月的口味"
- "高浓果肉搭配熬制工艺，色泽浓郁更稳定不吸水"
- "一袋一斤，正好做一个月的量"
- "做奶油/做内馅/淋面，一包搞定"
- "六寸蛋糕实际成本不到X块钱"
- "酥脆不软化，八小时不回潮不软化"

**促销叠加话术（核心！）**：
- "不仅买一送一，还叠加八三折优惠"
- "一件七五折的基础上，还能叠加平台大额优惠券"
- "限时折扣 + 买赠，错过再等一年"
- "年货节 + 平台消费券，叠加后到手才X毛多"
- "三件折扣太顶了，关键还叠加平台的消费券"

### 第四段：促销信息

目标：给出具体优惠，激发购买欲望

**限时紧迫感**：
- "活动随时会截止，需要的姐妹抓紧囤！"
- "趁着现在活动给力，还没入手的姐妹快囤起来吧！"
- "年货节就这一次，再不买过年可不发货了"
- "活动明天就要结束了，姐妹们抓紧囤起来"
- "趁现在价格划算，可真别再犹豫了"

### 第五段：促单话术

目标：引导点击下单

- "还没买的姐妹赶紧囤起来！"
- "需要的姐妹抓紧点击下方小黄车吧！"
- "趁着活动还没结束，刷到的姐妹赶紧冲！"
- "趁现在活动给力，抓紧囤上！"
- "手慢无，直接点击左下角！"

## 三、分品类脚本模板

### 刀叉模板

```
【开场钩子】
才X毛多一套！这个价格，买到就是赚到！

【痛点激发】
很多烘焙新手买刀叉只看价格，结果一用就傻眼——刀软得切不动，叉子一掰就断，盘子承重差，蛋糕放上去直接塌底。不光浪费钱，做出来的东西还特别难看。

【产品卖点展示】
给你看看我一直在用的法采刀叉。你看这个克重，X克，刀叉反复弯折不易断裂。再看这个餐盘，超厚白卡材质，承托力非常强，放个大蛋糕随便甩都不会掉。而且这套餐是五盘五叉，还带蛋糕刀，一套下来才X毛多，性价比拉满。

【促销信息】
现在X折活动，还能叠加平台优惠券，数量有限，抓紧抢！

【促单话术】
还没入手的烘焙人，这价格真的没理由不买！直接点击下方小黄车，手慢无！
```

### 翻糖膏模板

```
【开场钩子】
完了完了，姐妹们翻糖买早了！现在法彩翻糖膏买X送X模具了，不仅买一送一，还叠加X折优惠，气的我赶紧又买了两包！

【质地展示】
这个翻糖膏好揉好捏的质地，冬天也能轻松揉到拉丝状态。里边分成三小包，好揉好捏，分分钟揉出拉丝状态，塑形力拉满，不变形不开裂。

【场景应用】
搭配这个X模具，做蛋糕真是一点也离不开啊！

【促销叠加】
买一送一 + X折 + 送模具，三重优惠叠加，真的太划算了！

【促单话术】
活动随时会截止，需要的姐妹抓紧囤！
```

### 果酱/夹心脆模板

```
【开场钩子】
你们知道现在的烘焙技术已经到什么地步了吗？已经有这种X味果酱了！

【品质展示】
之前自己准备大几十才能做一个，现在法彩把它搬来线上，X块钱到手，足足X大包，近三个月的口味，抓紧趁活动囤。
（展示浓稠质地）高浓果肉搭配熬制工艺，色泽浓郁更稳定不吸水，拆开即用，轻松上手。

【使用场景】
做奶油/做内馅/淋面，一包搞定，口感特别好。

【促销叠加】
不仅X折，还能叠加平台优惠券，买的越多越划算！

【促单话术】
趁活动还没有下架，数量有限，能拍到的抓紧拍！
```

## 四、爆款元素清单

- ✅ 感叹号大量使用
- ✅ 情绪词：完了、真的、太、谁懂啊
- ✅ 价格数字具体化（X毛多、X克、不到X块）
- ✅ 多重优惠叠加描述
- ✅ 紧迫感（限时、限量、手慢无）
- ✅ 对比反差（前后对比、优劣对比）
- ✅ 口语化表达（姐妹们、直接用、就是、你看）
- ✅ 具体场景描述
- ✅ 具体克重/数量量化

## 五、品牌名称注意

- 法采 / 法彩 / 法塔 / 发财（同一个品牌不同脚本的写法，统一替换为"法采"）
- 视频脚本中用"法采"最准确
