# 法采短视频脚本生成

## 核心原则

- **帮到实处，无需缛节**：直接输出完整脚本，不要先列提纲再写
- **以爆款为模板**：严格遵循法采爆款脚本五段式结构
- **口语化**：脚本直接用于拍摄，读出来要自然顺畅
- **情绪饱满**：感叹号、重复词、口语语气词都要用上

## 输入

用户提供的产品信息（名称、规格、卖点、促销信息等），格式不限，可以是一句话也可以是详细描述。

## 输出格式

直接输出完整脚本，不需要额外说明。脚本格式参考 `references/脚本格式与话术库.md`。

## 工作流程

### 第一步：提取产品信息

从用户输入中识别：
- 产品名称（刀叉、翻糖膏、果酱、夹心脆、抹茶酱、奶冻粉等）
- 规格（克重、包数、包含内容）
- 品质卖点（克重、韧性、承托力、分装设计、口感等）
- 促销信息（折扣、买赠、限时、活动名称）
- 目标用户痛点

### 第二步：选择脚本模板

根据产品类型选择对应脚本模板（见 `references/脚本格式与话术库.md`）：
- **刀叉类**：开场钩子 → 痛点激发 → 卖点展示 → 促销信息 → 促单话术
- **翻糖膏类**：后悔共鸣 → 促销叠加 → 质地展示 → 场景应用 → 促单
- **果酱/夹心类**：对比反差 → 品质展示 → 使用场景 → 促销叠加 → CTA
- **其他品类**：按实际情况选择最接近模板

### 第三步：填充内容

将产品信息填入模板，注意：
1. **开场钩子**：用价格钩子或情绪钩子，前3秒抓住注意力
2. **痛点/对比**：精准描述用户痛点，引发共鸣
3. **卖点量化**：用具体数字（克重、价格、折扣）而非模糊描述
4. **促销叠加**：把多重优惠（折扣+买赠+平台券）全部叠加说出来
5. **促单话术**：紧迫感 + 直接引导点击

### 第四步：输出脚本

直接输出完整脚本，格式示例：

```
【开场钩子 - 前3秒】
才X毛多一套，便宜到不敢相信！

【痛点激发】
很多烘焙人……（痛点描述）

【产品卖点展示】
你看我一直在用的法采……（品质展示+量化数据）

【促销信息】
现在……活动……（多重优惠叠加）

【促单话术】
还没买的姐妹……（紧迫感+引导）
```

## 质量检查

输出前自检：
- [ ] 读起来口语化吗？有无书面语？
- [ ] 感叹号、情绪词够不够？
- [ ] 价格/折扣信息准确吗？
- [ ] 有无具体数字支撑（克重、折扣、到手价）？
- [ ] CTA是否直接有力？
