# 每日早间简报

快速汇总今日关键信息，帮用户在 30 秒内了解今天要关注什么。

## 工作流程

### 第一步：获取数据（并行）
同时调用：
1. `lark_get_calendar_events(today)` — 今日日程
2. `lark_get_my_tasks()` — 所有待办任务

### 第二步：筛选关键信息
- 日程：按时间排序，标注重要程度
- 任务：列出今日截止 + 已逾期的高优先级项
- 如果有关联，标注"会议前需准备XX"之类的提醒

### 第三步：输出简报

```markdown
## ☀️ [日期] 早间简报

### 📅 今日日程
| 时间 | 事项 | 备注 |
|------|------|------|
| 09:30-10:30 | 产品周会 | 需准备上周数据 |
| 14:00-15:00 | XX项目评审 | |
| 16:00-17:00 | 1:1 沟通 | |

### 📋 待办提醒
- 🔴 [逾期] 提交Q2预算 — 应于昨天完成
- 🔴 [今日] 完成PRD初稿 — 今天截止
- 🟡 [本周] 更新技术方案文档

### ⚡ 今日建议
- 上午先完成PRD初稿（今天截止）
- 13:00 前准备好产品周会的数据
- 评审会后跟进XX项目的接口联调

### 📊 本周概览
- 共 X 项任务待完成
- 本周有 X 个会议
```

## 注意事项
- 简短有力：用户应该在 30 秒内看完
- 突出重点：逾期/今日截止的标红
- 给出建议：不只是展示，还要给出行动优先级
- 语气积极：用鼓励的方式开始新的一天
